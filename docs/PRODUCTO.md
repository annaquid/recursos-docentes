# Diseño funcional

## Experiencia

Escape room matemático individual, presencial, de 60 minutos. Todos los estudiantes realizan las mismas misiones y retos; la puntuación y el progreso se registran individualmente.

## Narrativa provisional

Una instalación de investigación ha quedado bloqueada. El alumnado debe recuperar cinco fragmentos del código de emergencia resolviendo cinco salas.

## Distribución temporal

- 00–05: introducción y acceso.
- 05–15: sala 1, relaciones binarias.
- 15–27: sala 2, equivalencia y orden.
- 27–39: sala 3, divisibilidad, Euclides y Bézout.
- 39–49: sala 4, congruencias y aritmética modular.
- 49–57: sala 5, congruencias lineales.
- 57–60: código final y cierre.

## Principios de interacción

Evitar el formato de test convencional. Priorizar:
- Construcción y manipulación de relaciones, matrices y diagramas.
- Introducción de pasos intermedios y validación progresiva.
- Detección y corrección de errores.
- Descubrimiento de regularidades y resolución de mecanismos.
- Explicaciones breves en puntos seleccionados.

## Modo de juego

- Acceso mediante código de sesión y alias.
- Inicio y pausa controlados por el profesor.
- Tiempo global y progreso por sala.
- Sin mostrar soluciones durante la partida.
- Pistas opcionales con penalización, según configuración.
- Registro de acciones necesarias para calcular puntuación y analizar dificultades.

## Límite anti-IA

Una web en dispositivos personales no puede impedir que el alumno abra otra pestaña, use otro dispositivo o consulte una IA. El diseño reduce la utilidad de copiar respuestas, pero no garantiza el bloqueo técnico. Para una evaluación controlada se requiere supervisión y, si se necesita, dispositivos o navegador gestionados.
